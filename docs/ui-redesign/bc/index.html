B é o modo toque e C o modo controle. Em Automático, conectar um controle troca para o C e desconectar volta ao B; também dá para fixar um dos dois aqui ou em Configurações → App. O controle funciona pela Gamepad API abrindo docs/ui-redesign/bc/index.html direto no navegador; dentro do visor de artefatos o navegador pode bloqueá-lo. Capas, sessões, perfis, drivers e números são dados de exemplo.
